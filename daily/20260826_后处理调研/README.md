# 手机录像创新功能与 ISP 后处理调研

本目录用于记录手机录像、计算摄影、相机玩法和端侧后处理方向的持续调研。

## 研究范围

- 以手机录像为最终落点，纳入实时预览、录制在线处理、录后端侧处理和云端重处理。
- 关注手机厂商、专业相机、电影机、运动相机、无人机、AR/VR、短视频应用、专业后期软件、论文和专利。
- 动态虚拟打光、星芒作为已有方向继续保留，但本轮扩展到更完整的录像后处理创新图谱。
- 同时纳入忠实增强、感知增强和生成式创作，并明确真实性边界。

## 证据等级

- `E1`：已量产，来自官方产品页、说明书或支持文档。
- `E2`：公开演示或有限发布，来自白皮书、SDK、官方 Demo 或发布资料。
- `E3`：学术原型，来自论文、补充材料、代码或实验报告。
- `E4`：公开专利或技术储备，不代表已量产。
- `E5`：本项目基于证据推演的创新方案，不是行业事实。

## 目录

- `metadata/`：统一 schema、搜索日志、候选功能和评估记录。
- `sources/`：官方产品、论文、代码、数据集、专利和来源清单。
- `figures/`：来源截图和本项目生成的统计图、架构图。
- `notes/`：阶段性筛选、深度解析和最终审计。
- `matrix/`：Excel 机会库及其结构检查结果。
- `report/`：Markdown 和 Word 洞察报告。

## 研究工作流

1. 收集和缓存可核验来源。
2. 统一记录产品原型、论文方法、专利方案和本项目推演。
3. 建立不少于 100 条候选功能。
4. 深挖约 30 个方向，形成约 10 个组合创新概念。
5. 输出可筛选 Excel 和适合连续阅读的 Word 报告。

本目录中的“已实现”“论文提出”“专利提出”和“建议探索”必须分开阅读，不能相互替代。
