# FLUX 系列模型与超分辨率技术洞察报告设计

## 1. 目标

在 `D:\Repository\ReadPaper\daily\Flux` 建立可长期维护的 FLUX 学习资料库，下载并核验相关论文 PDF、官方模型卡与技术资料，最终形成一份中文主叙述、英文术语标注、以论文原图为主要视觉材料的深度 Word 学习手册。

报告按照以下顺序展开：

1. DiT
2. Rectified Flow
3. Flow Matching
4. Stable Diffusion 3 / MM-DiT
5. FLUX.1 模型结构与模型卡
6. FluxSR
7. DreamSR
8. OP4KSR
9. FoA-SR
10. LucidFlux / ResFlow-Tuner
11. 量化、蒸馏和端侧加速

## 2. 收录边界

### 2.1 全量收录

检索截止日期为 2026-08-03。凡论文正文明确将 FLUX.1 或 FLUX.2 用作以下任一角色，均纳入论文库和索引：

- 基础模型或主干网络；
- 教师模型或蒸馏对象；
- 训练、微调或参数高效适配对象；
- 量化、剪枝、缓存、低步采样或系统加速的主要实验对象；
- 主要基线或核心评测模型。

仅在相关工作中顺带提及 FLUX、仅使用通用 Flow/DiT 方法且未实际实验 FLUX、或关键词中的 `flux` 与生成模型无关的论文不纳入全量 FLUX 集合。

### 2.2 理论基础

DiT、Rectified Flow、Flow Matching、SD3/MM-DiT 等论文即使未使用 FLUX，也作为理解 FLUX 架构和训练目标的理论基础收录。该部分不宣称属于 FLUX 系列论文。

### 2.3 证据要求

每篇论文至少保留以下证据：

- 标题、作者、年份、发表状态、arXiv/DOI/官方页面；
- 正文中使用 FLUX 的原句或明确方法描述；
- FLUX 版本和承担角色；
- 本地 PDF 路径与文件哈希；
- 来源 URL 和检索日期。

## 4. 报告结构

### 4.1 开篇

- 阅读路线和先修知识；
- FLUX 系列的公开资料边界；
- 生成模型、Flow Matching 与真实图像超分的关系；
- 关键术语和符号预览。

### 4.2 理论基础篇

依次解释 DiT、Rectified Flow、Flow Matching、SD3/MM-DiT。重点建立以下概念链：

`latent representation -> velocity field -> probability path -> Transformer denoiser -> multimodal joint attention -> FLUX`。

### 4.3 FLUX 基础模型篇

- FLUX.1-dev、FLUX.1-schnell、FLUX.1-pro 与已公开版本关系；
- 官方模型卡可确认的信息与未公开的训练细节；
- MM-DiT、VAE、文本编码器、RoPE、Flow Matching 和采样流程；
- FLUX.1 Kontext 等官方后续技术报告；
- 许可证、可用性和复现边界。

### 4.4 超分主线篇

FluxSR、DreamSR、OP4KSR、FoA-SR 按时间和技术继承关系逐篇深讲，并建立横向比较：

- 一步、多步与两阶段推理；
- 分块和无分块 4K；
- FLUX.1 与 FLUX.2；
- 生成细节、参考保真度和幻觉风险；
- VAE 压缩率、RoPE、全局/局部条件和蒸馏；
- 推理时间、硬件、显存与部署可行性。

### 4.5 图像复原扩展篇

详细解析 Acquire and then Adapt、LucidFlux、ResFlow-Tuner，并纳入其他符合收录边界的 FLUX 图像复原论文。

### 4.6 效率篇

全量纳入符合边界的量化、蒸馏、剪枝、缓存、低步采样、算子和系统加速论文。代表性论文采用完整案例模板；其余论文进入统一矩阵，至少记录：

- FLUX 版本；
- 优化对象；
- 位宽、步数、稀疏率或缓存策略；
- 设备和软件环境；
- 延迟、吞吐、显存和质量变化；
- 是否开源及复现状态；
- 对云端、桌面端和移动端的适用性。

### 4.7 综合洞察篇

- FLUX 低层视觉的发展路线；
- 为什么 FLUX 适合真实图像超分；
- 感知生成与观测真实性的根本张力；
- 手机数字变焦、云端精修和端侧相机的迁移条件；
- 当前研究缺口和分阶段学习计划。

## 5. 单篇深度案例模板

每篇主线论文包含：

1. 论文元数据、机构和发表状态；
2. 研究问题与前序方法缺陷；
3. 原文架构图及 Figure 编号、PDF 页码；
4. 模块级方法和数据流解析；
5. 关键公式、符号与中英文术语；
6. 训练数据、损失函数、训练策略和推理流程；
7. 原文效果图、核心表格和消融实验；
8. 创新点、解决的问题和证据强度；
9. 局限性、幻觉风险、复现状态；
10. 与前后论文的继承关系及工业启示。

## 6. 视觉材料规范

- 优先使用论文原文架构图、流程图、效果图、表格和公式截图；
- 每幅截图注明论文简称、Figure/Table 编号和本地 PDF 页码；
- 裁剪图必须保持原始宽高比和可读分辨率；
- 不用自绘图替代论文原图；只有跨论文关系无法由原图表达时，才允许加入简洁的汇总图；
- 不将参考文献页或无关正文误标为实验图，所有截图需视觉复核。

## 7. 索引工作簿

`FLUX论文索引.xlsx` 至少包含以下工作表：

- `阅读主线`：推荐顺序、预计难度、先修知识和阅读状态；
- `全量论文`：全部纳入论文及证据字段；
- `超分与复原`：任务、模型、数据集、指标和技术贡献；
- `效率优化`：量化、蒸馏、缓存、剪枝和部署指标；
- `下载清单`：本地文件、来源、哈希和下载状态；
- `排除记录`：候选论文及排除理由。

## 8. 质量与验收标准

- PDF 能正常打开，页数大于零，文件哈希已记录；
- 去重依据优先使用 arXiv ID/DOI，其次使用规范化标题；
- 全量论文必须有正文 FLUX 使用证据，不能仅凭标题或摘要猜测；
- Word 中的关键数值回溯到原文表格或正文；
- 清楚区分论文事实、作者解释和报告分析；
- 不把感知质量领先等同于真实细节恢复准确；
- DOCX 使用 Microsoft YaHei 中文字体和紧凑参考手册风格；
- 最终 DOCX 导出 PDF 并逐页检查图片、表格、中文字体、分页和页眉页脚；
- 报告、索引和全部下载文件最终保存在 `daily\Flux`。

## 9. 非目标

- 不尝试重现全部论文训练；
- 不下载模型权重或大规模训练数据；
- 不把泛用 DiT/Flow 论文无限扩展为完整生成模型综述；
- 不对未公开的 FLUX 训练数据和训练配方作无证据推断。
